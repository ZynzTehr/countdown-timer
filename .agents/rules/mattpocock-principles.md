# Engineering Principles & Disciplines (Matt Pocock Skills)

## Core Mindset
- **No Vibe Coding**: We do real, rigorous engineering. Inspect real code, check actual state, test seams, and verify output.
- **Finding facts is the agent's job, never the user's**: Never ask the user for facts you can determine yourself using tools, file searches, inspection, or subagents.
- **Verification First**: Always run builds (`npm run build`), test scripts, and perform browser visual verification before declaring a task done.
- **Attention to Craft**: Details matter. Aesthetics matter. Micro-interactions matter. If building UI, it must be state-of-the-art, responsive, accessible, and delight the user.
- **Clarity and Precision**: Keep communications grounded, calm, and actionable. Do not hallucinate or skip steps.
